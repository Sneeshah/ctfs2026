# ctf2026

Security lab writeups, documented -not just solutions, but description, reproduction, impact, and remediation.

Each writeup follows a consistent finding format: see [`TEMPLATE.md`](./TEMPLATE.md). Writeups older than XSS follow the format found in [`TEMPLATE_OLD.md`](./TEMPLATE_OLD.md).

## Topics
- **Web** — XSS, SQL injection, path traversal, SSRF, OS command injection,
  access control, authentication, file upload, information disclosure
- Crypto / pwn / reversing — planned

## Structure
One folder per vulnerability class; labs numbered within.
